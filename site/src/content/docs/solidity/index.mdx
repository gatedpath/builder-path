This is the path for the person who writes the contract. If you would rather describe what you want and review what comes back, the other section, [Directing an agent](/agents/), is yours, and every [project](/tutorials/) has a track for each. The two meet at the same proof: the same tests, the same pre-flight, the same refusals.

I wrote these in the order a dApp gets made. Each one is short, each is built on code that compiles in this repository, and I ran every command on 17 September 2026 before writing it down. They are step cards with a checklist, like the projects, and your ticks stay in your own browser.

## Before you start

You need a clone of the repository, Node 22 or later and Foundry. [Start here](/start/) checks the machine. Tutorials 1 and 2 run inside `packages/receptor-mock`, 3 and 5 inside `packages/contract-kit`, and 4 and 6 inside a project the scaffolder makes. Each package needs one command the first time, which fetches the pinned libraries:

```sh
npm run setup
```

## Then pick a project

When the stages make sense, the [projects](/tutorials/) are where you use them. [Project 1](/tutorials/change-the-gate/) has a full "Writing Solidity" track that was done by hand; the others will gain theirs as each is run.
