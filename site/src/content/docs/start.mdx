This is one path, and it does not branch. At the end of it you have a verified wallet, testnet coins, a project compiled for Prague, one function gated behind a credential, and the whole thing running locally with five wallets in five credential states and a switch to move between them. I ran the path twice on 14 September 2026 on fresh scaffolds, the local loop against an Anvil fork of testnet and the switcher in a real browser; both transcripts, with every command and wall time, are in the scaffolder's `reports/` folder. The evening run, on the Foundry-only default this page now describes and with the `doctor` and gas steps added, took 1 minute 47 seconds of tool time (`golden-path-dev-2026-09-14b.md`). The morning run took 1 minute 13 seconds without those two steps and with a warmer npm cache; the one line that moved was `npm install`, at 42.6 s against 30 s. The 12 September run took nineteen minutes and six commands in two shells for the same loop, and that transcript is beside the others. Every step says whether it has been run, and where.

## The path

<StepList>
1. ### Verify your wallet

   <StatusPill variant="neutral" label="Your step: only you can do this" tipKey="verify-wallet" />

   Every wallet on Redbelly is identity-verified before it can send anything. Verification is a passport plus a biometric check, done once, at the Access dApp. A credential issued on testnet carries over to mainnet.

   <VineAside href="https://vine.redbelly.network/identity/user-access/" label="Vine: user access">
   Claim an access credential from an accredited issuer, then self-enable write access through a network contract. That is the whole flow; Vine has the screenshots.
   </VineAside>

   Go to [access.redbelly.network](https://access.redbelly.network). Once you are done, the network's permission contract answers true for your address. Every later tool relies on this read, and it needs nothing from Redbelly:

   <Sample id="helpers-is-allowed" title="test/unit.test.mjs (the isAllowed read, replayed against measured values)" />

   The same read from the command line, once Foundry is installed in step 3:

   ```sh title="Is this wallet allowed on 153?"
   cast call 0x519ba1b48D571FD92FAF6FE4D20fe74Ca435B690 "isAllowed(address)(bool)" 0xYourWallet --rpc-url https://governors.testnet.redbelly.network
   ```

   <StatusPill variant="verified" label="Run 14 Sep 2026 against the real testnet" /> This exact `cast` call answered `true` for the known allowed address and `false` for the zero address, read-only, in 2.0 s and 1.2 s each.

3. ### Install a toolchain

   Vine's own material is Hardhat, Waffle and Remix. I have kept this path to Foundry only, because `forge`, `cast` and `anvil` are what the local loop, the gas report, the ship report and the deploy step are built on: `anvil` runs the fork, `forge` deploys and tests, and both sign locally from a keystore when the time comes. A second toolchain doubles what can drift, and the one compilation fault in the 12 September runs was Hardhat's, so since wave 8 the scaffold is Foundry only unless you pass `--hardhat`, which adds a Hardhat 3 view of the same sources for a team that also uses it; its steps were run on 12 September and its compile is re-run in the scaffolder's tests.

5. ### Check the machine, then install

   First the machine. `npm run doctor` works on the bare scaffold, before anything is installed: Node 22 or later; `forge`, `anvil` and `cast` on PATH, one version, and the real binaries rather than the npm wrapper that drops exit codes; `slither` and `aderyn` (optional, a warning when missing); git; no `.env` tracked; and `vendor/` against the versions the scaffolder recorded in `package.json`. One line per check with the fix on the same line; exit 0 only when every required check passes. Hackathon participants lose their first hour to this list, so it runs in under a second.

   ```sh title="From my-app/"
   npm run doctor
   ```

   <StatusPill variant="verified" label="Run 14 Sep 2026: 0.9 s, ten pass, one warning" /> Every required check passed on the build machine; the one warning was Aderyn, which is optional and whose npm wrapper cannot fetch its binary behind this environment's proxy. A pasted `doctor` line means the same thing to the MCP server's `explain_failure`, because both read one failure table.

   Then install. A fresh scaffold has nothing installed, and `npm run dev` or `forge build` straight away stops with the two commands you skipped. The scaffolder prints the same two as its next steps.

   ```sh title="From my-app/"

   npm run contracts:install    # OpenZeppelin 5.6.1 from npm, forge-std v1.16.2 with forge install --no-git
   ```

   <StatusPill variant="verified" label="Run 14 Sep 2026: 42.6 s and 3.3 s" /> Most of the first command is Next.js and wagmi; the morning run the same day measured 30 s with a warmer npm cache and the 12 September run 72 s cold. 8. ### Gate one function, and prove it

Forgetting the hook is a compile error, on purpose.

9. ### Check before you sign

   There are three checks, none of which signs anything, and I ran all three on this page's date on the scaffold the local loop had just run in. The first is static analysis: `npm run lint:slither` runs Slither the way CI does and writes the report plus a hash of the sources beside it, so pre-flight can tell whether the report describes the code as it is.

   ```sh title="From my-app/"
   npm run lint:slither
   ```

   <StatusPill variant="verified" label="Run 14 Sep 2026: 17 contracts, 81 detectors, 3 results, none at the fail level" /> The three are the same low-impact `timestamp` notes on `IssuerRegistry` that the contract kit triaged when it landed (an issuer window compared against `block.timestamp`, which is the intent); Slither exits 0 on them and pre-flight accepts the report.

   Then the two pre-flights. Both read the real testnet with a public address and nothing else: chain id, `isAllowed`, the balance, the Safe when there is one.

   ```sh title="From my-app/: the scaffold's own script, then the seven-check CLI"
   DEPLOYER=0xYourWallet npm run preflight
   cd contracts && redbelly-preflight --chain 153 --address 0xYourWallet
   ```

   <StatusPill variant="verified" label="Run 14 Sep 2026 read-only against 153 with the known allowed address, twice" /> The scaffold's script passed 10 of 10 checks.
